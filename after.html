Afterlight

The walk is over,
but the path remains.

You have passed through the gate and into the hall. The moonlight that fell on the worn stones was the same light that has fallen there for centuries, patient and unchanging.

There is nothing more to see here. The temple does not ask for your attention — it only asks that you were present for the walk.

Return whenever the noise gets loud. The path is always the same, and never the same light.

Return to the gate

KAGE — a quiet mountain temple
